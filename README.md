# Laboratorio-Reconocimiento-Escaneo-Nmap

Sobre este proyecto:
Este repositorio documenta un proyecto basico de escaneo de redes y puertos, con el fin de un aprendizaje practico en ciberseguridad, fue un laboratorio controlado usando Virtualbox con dos entornos, Kali Linux y Metasploitable 2.

Maquina de analisis: Kali Linux

Maquina vulnerable: Nmap

IP Kali Linux: 10.10.10.6

IP Metasploitable 2: 10.10.10.6

Las direcciones anteriores corresponden a direcciones virtuales diseñadas para el laboratorio, no deben interpretarse como direcciones reales.

La prueba se realizo en un entorno propio y controlado, no sobre un sistema de terceros
